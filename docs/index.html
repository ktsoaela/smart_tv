The room

It keeps the quiet parts.

Profiles
The circle by the clock is a person. Each profile keeps its own My List and sample Continue watching. Add, rename, switch, or remove one.
Search
An on-screen keyboard, genre shortcuts, live results, and voice where the browser supports it.
Preview
A one-minute preview. Controls hide on their own. Skip 10 seconds, captions, and an Up next countdown.
The room
The same layout at 1080p and 4K. Reduce motion, larger text, a high-contrast focus ring, and an ambient screen when the room is idle.
Wallpaper
Home can sit on this computer’s desktop wallpaper. A volume panel appears when the volume changes.
Weather
A forecast for this computer while the app is open. The place is not written down.
Sign-in
Sign in once inside the Windows app and it stays signed in. Settings can sign out of all apps. The public page stores nothing.
First run
Setup picks a Minimal or Busy Home, your apps, the weather, and a wallpaper. Move, rename, hide, or remove any app afterward.

Run it

Open the launcher.

The browser path needs Python 3. The Windows app needs Node.js. Both live in this repository.

Browser

This computer

Starts the companion on this machine and opens the launcher. My PC, Chrome shortcuts, wallpaper, volume, and sources need it.

py server.py

From a TV on your network: py server.py --lan

Windows

Full-screen app

Takes the display. Sites open inside the window, and the remote’s Back closes them. The downloaded exe does not need Node.js.

Smart-TV.exe

npm install
npm start

Windows app guide

A demo with no PC features is index.html in the repository. Keys, the network address, and Google TV hardware are in the guide. Source is on GitHub.

Smart TV

A TV launcher you run in a browser and drive with a remote. A television can still use a Google TV Streamer. This repository is the launcher you can open and try.

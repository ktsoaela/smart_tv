What you get on Home

The screen is built for a television. Focus moves to the nearest item, and each row remembers where you were.

Continue watchingWhile the app is open, a page you open can sit at the front of the row. Close Smart TV and that row is gone.
ProfilesThe circle by the clock is a profile. Each person keeps their own Continue watching and My List.
Your appsAdd a website or a PC program. Move, rename, hide, or remove any tile.
My PCBrowse folders with the remote and play videos, music, and photos, with resume and a slideshow.
SearchAn on-screen keyboard, genre chips, and voice where the browser supports it.
SetupThe first run picks a Minimal or Busy Home, your apps, the weather, and a wallpaper.

Apps stay in the window

On Windows, streaming apps open inside Smart TV. Hold Back and it asks before you leave. Home then zooms and fades in. HDMI, Chrome, and the desktop still use the source line.

Inside the TVThe app fills this window. Back goes back in the app. Hold Back asks if you want to go Home, then Home zooms and fades in.
Nothing kept from the sitesSign-ins inside the TV live in memory. Close the app and they are gone. The public page stores nothing.
SourceHDMI 1 is Smart TV. HDMI 2 opens a browser. HDMI 3 shows the desktop. Coming back from those plays the source screen.

Run it

The browser launcher needs Python 3. The Windows app needs Node.js. Both are in this repository.

Browser

This computer

Starts the companion and opens the launcher. My PC, Chrome shortcuts, wallpaper, and volume need this.

py server.py
Windows

Full-screen app

Takes the display like a TV box. Apps open inside the window. Details are in the Electron guide.

npm install
npm start
